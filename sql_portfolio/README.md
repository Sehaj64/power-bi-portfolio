# SQL Business Analytics Portfolio Case Studies

This section of my portfolio contains 50 solved SQL queries and 5 end-to-end analytical case studies designed to showcase SQL proficiency for data analytics roles.

---

## 🗂️ Folder Structure

* **[queries_50.sql](queries_50.sql)**: A master script with 50 graded questions covering standard business aggregates, window functions, complex joins, CTEs, and customer cohorts.
* **[case_studies/](case_studies/)**:
  * **[01_sales.sql](case_studies/01_sales.sql)**: Retail sales trends, profit leakage, and regional analysis.
  * **[02_churn.sql](case_studies/02_churn.sql)**: SaaS subscription metrics, active user trends, and lifetime customer values.
  * **[03_hr.sql](case_studies/03_hr.sql)**: Employee salary distribution stats, yearly tenure levels, and compensation discrepancies.
  * **[04_ipl.sql](case_studies/04_ipl.sql)**: Sports analytics modeling batsman strike rates and bowler economy metrics.
  * **[05_finance.sql](case_studies/05_finance.sql)**: Budget variance audits, AR aging risk calculations, and EBITDA summaries.

---

## 💡 SQL Concepts Showcased

1. **Window Functions**: For rankings (`DENSE_RANK()`, `ROW_NUMBER()`), moving averages (`AVG(...) OVER(...)`), and offset trends (`LEAD()`, `LAG()`).
2. **Common Table Expressions (CTEs)**: Writing highly organized, readable, and query-optimized code blocks.
3. **Complex Aggregations**: Implementing conditional grouping using `CASE WHEN` clauses (cohort mapping, price categorizations).
4. **Relational Joins**: Connecting multiple entities across transactional and lookup directory tables.
